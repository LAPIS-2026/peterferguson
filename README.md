# Códigos y Datos para Práctico — Prof. Peter Ferguson (LAPIS 2026)

Repositorio de materiales y acceso a datos para el práctico del Profesor Peter Ferguson (*Stellar Streams in Photometric Surveys: Discovery, Characterization, and Modeling*) en la escuela de astrofísica **XII LAPIS 2026**.

## Proyecto

- Construcción de un *pipeline* de detección de corrientes estelares (*stellar streams*) desde cero usando un filtro adaptado (*matched filter*) basado en isócronas en el espacio color-magnitud sobre datos de DES, recuperación de corrientes conocidas (ATLAS, Phoenix, Tucana III) e inyección de corrientes sintéticas con `streamobs` para estimar la eficiencia de detección.

## Datos y Catálogos

- **DES Y6 Gold Catalogue (LSDB — US-West, HTTP)**: [`http://data.lsdb.io/DES/DES_Y6_Gold_(US-West%2C_HTTP)`](http://data.lsdb.io/DES/DES_Y6_Gold_\(US-West%2C_HTTP\))
